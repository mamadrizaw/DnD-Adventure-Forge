# D&D Adventure Forge — راهنمای فارسی

این پروژه یک سناریوساز D&D با رابط وب است. با پایتون ساخته شده و در مرورگر اجرا می‌شود.

## امکانات
- تنظیم نسخهٔ قوانین، ژانر، سطح گروه، تعداد بازیکنان و مدت جلسه
- تولید صحنه‌ها، NPCها، سرنخ‌ها، برخوردها، پیچش داستانی و پایان‌های مختلف
- نمایش محتوا در تب‌های جداگانه
- خروجی Markdown و JSON و ذخیرهٔ محلی
- موتور داخلی بدون API و موتور اختیاری هوش مصنوعی

## نصب و اجرا در ویندوز
1. ZIP را استخراج کن و پوشه را در VS Code باز کن.
2. از منوی **Terminal → New Terminal** ترمینال را باز کن.
3. محیط مجازی بساز و فعال کن:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

اگر فعال‌سازی PowerShell مسدود بود، در CMD اجرا کن:

```bat
.venv\Scripts\activate.bat
```

4. کتابخانه‌ها را نصب کن:

```powershell
python -m pip install -r requirements.txt
```

5. برنامه را اجرا کن:

```powershell
python -m streamlit run app.py
```

مرورگر معمولاً خودکار باز می‌شود؛ در غیر این صورت آدرس محلی نشان‌داده‌شده در ترمینال (معمولاً `http://localhost:8501`) را باز کن.

## موتور هوش مصنوعی (اختیاری)
در نوار کناری «هوش مصنوعی» را انتخاب کن و یک کلید API معتبر وارد کن. استفاده از API ممکن است هزینه داشته باشد. کلید را در کد یا فایل قابل اشتراک ذخیره نکن. اگر کلید نداری، موتور داخلی بدون API کار می‌کند.

## محدودیت‌های فعلی
- موتور داخلی از الگوهای برنامه‌نویسی‌شده استفاده می‌کند؛ برای تنوع و منطق روایی پیشرفته‌تر، موتور هوش مصنوعی مناسب‌تر است.
- پیشنهادهای برخورد تضمین قطعی تعادل مبارزه نیستند؛ پیش از بازی آن‌ها را با قوانین و ترکیب واقعی گروه بازبینی کن.
- ذخیره‌سازی روی همان رایانه است و حساب کاربری یا همگام‌سازی ابری ندارد.

## فایل‌ها
- `app.py`: برنامه و رابط کاربری
- `requirements.txt`: کتابخانه‌های لازم
- `saved_adventures/`: محل ذخیرهٔ سناریوها
